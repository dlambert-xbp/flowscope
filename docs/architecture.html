Invariants worth knowing

One fan-out per data type

flows every parser calls record.Emit → hot ring + batcher. snmp walks go through the worker pool. alerts route through the engine. New features extend these — they don't bypass them.

Counters > flows

Anywhere the UI shows a rate, counter-sample diffs win over flow-bucketed aggregation. The timeseries endpoint labels its response source: counters | gnmi | flows so the operator knows what they're looking at.

Pollerless-first

Receivers, not interrogators. We don't poll for anything streaming telemetry or sFlow counters already provide. SNMP polling fills the gaps inventory needs, not the per-interface bandwidth gauges.

TLS at the edge

App Gateway / nginx / Caddy terminates TLS. The Go services speak plain HTTP inside the cluster. Auth on the wire is X-Auth-Token today, OIDC/Entra ID later.

Forward-only schemas

Migrations are idempotent and forward-only. They run from a one-shot init container before new pods take traffic. No external migration tool.

Data stays in-tenant

No SaaS callbacks. The only outbound traffic is what the operator configures: webhook URLs, SMTP relay, syslog server.
