SNMP credential resolution.

How the snmp service decides which credential to use when walking an exporter. Resolution runs once per walk; per-exporter bindings live in snmp_credentials, fleet-wide defaults in snmp_global_defaults, and the legacy env-var community in FLOWSCOPE_SNMP_COMMUNITY.

Resolved-credential paths

case binding_kind secrets come from notes
Per-exporter inline custom snmp_credentials row community / v3 fields on the binding itself
Per-exporter → global v2c global_v2c snmp_global_defaults role='v2c' per-exporter port overrides global port
Per-exporter → global v3 global_v3 snmp_global_defaults role='v3' per-exporter port overrides global port
No binding · v2c global configured — snmp_global_defaults role='v2c' fleet-wide v2c is the default community for unbound exporters
No binding · no global — FLOWSCOPE_SNMP_COMMUNITY env var legacy fallback · log a warning if unset
