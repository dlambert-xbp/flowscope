Auto-bind order for flow-discovered exporters

  1. 1 hq-readonly-v3 v3
  2. 2 dc-east-v2c v2c
  3. 3 aristaro-v3 v3
  4. 4 arista-v3 v3

When a new exporter is observed in flow ingest without a binding, these profiles are tried in order until one answers. The first profile uses a 1s tight timeout; subsequent profiles use the full SNMP timeout. SNMP errors (auth, decrypt) keep trying the next profile; total silence on profile #1 skips the device.

This order is for flow auto-bind only — bulk scans pick a single profile (see below).
